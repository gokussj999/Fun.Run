# AI Development Rules

## Read First

Always read:

- 00_PROJECT.md
- 01_ARCHITECTURE.md
- 02_RULES.md
- 03_ROADMAP.md
- 04_CURRENT_PHASE.md

before starting any task.

---

## Repository Rules

Never scan the entire repository.

Only open files required for the current task.

---

## Solana Program

Never modify the Solana program.

The protocol is frozen.

Only change it if the project owner explicitly requests it.

---

## Backend

Never change backend architecture without approval.

Follow existing coding patterns.

---

## Frontend

Frontend is responsible only for UI/UX.

Do not move business logic into the frontend.

---

## Code Quality

Write production-grade code.

Keep code clean, modular, reusable, and scalable.

---

## Before Coding

Always explain the implementation plan first.

Never start coding immediately.

---

## If Information Is Missing

Ask the project owner instead of making assumptions.
